# Temperature Converter (C++)

### Description
A menu-driven Temperature Converter developed in C++. This application allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin using standard conversion formulas.

### Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Menu-driven interface
- Input validation for Kelvin values
- Perform multiple conversions in a single run
- Displays results up to 2 decimal places

### Technologies Used
- C++
- Standard Library (`iostream`, `iomanip`)

### Conversion Formulas

- **Celsius to Fahrenheit**
  ```
  °F = (°C × 9/5) + 32
  ```

- **Celsius to Kelvin**
  ```
  K = °C + 273.15
  ```

- **Fahrenheit to Celsius**
  ```
  °C = (°F − 32) × 5/9
  ```

- **Kelvin to Celsius**
  ```
  °C = K − 273.15
  ```
